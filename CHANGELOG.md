## [Unreleased]

### Added
- **`/video-shotcraft` in the media module** — shot design for *product* video (framing, camera move, lighting, pacing, card by card) from `Vincentwei1021/video-shotcraft` (Apache-2.0, 3.7k★), commit-pinned at `0022ec4`. Orthogonal to `/watch`, which covers talking-head and tutorial footage. Documented honestly: the ~104 shot cards are written in Chinese — the scaffolding is English and Claude reads the cards fine, but anyone opening the reference files expecting English prose should know first. Bump `SHOTCRAFT_COMMIT` to update.
- **AI film pipeline skills (5) in the media module** — `/ai-film-director`, `/story-bible-builder`, `/cinema-worldbuilder-pro-30`, `/banana-pro-director-3.0`, `/video-qa`, from `A0339x/ai-film-pipeline` (MIT), commit-pinned at `5314221`. Bump `AIFILM_COMMIT` to update.
  - **Provenance is documented rather than glossed.** This is the repo's thinnest dependency chain: a small personal collection (single-digit stars, no forks, first published 2026-05-14) whose LICENSE is MIT but which GitHub reports as `NOASSERTION` due to a custom copyright preamble, and where two of the five skills derive from Joey of *CTRL: Hunters* on the strength of a spoken "take them, use them, modify them" grant in a YouTube video rather than a written license. Pinning is the mitigation — a pull or rewrite upstream fails loudly instead of silently changing what installs. README states the trade-off and tells the reader they can skip the module.
  - **Frontmatter names ≠ folder names.** Two skills install under a version-suffixed name their source folders don't carry (`banana-pro-director/` declares `name: banana-pro-director-3.0`). Since `install_skill_pack_pinned` installs by frontmatter name — which is also the slash command — both the install verification and the uninstall list key off the frontmatter names. Verifying or removing by folder name silently misses them; the installer's first cut did exactly that and reported a false failure despite all 5 skills landing correctly.
  - Install verification uses an array with `"${expected[@]}"` rather than a space-separated string with unquoted word splitting, matching the `"${SKILL_NAMES[@]}"` idiom already used elsewhere in the file — it doesn't depend on what `IFS` happens to be when the function runs.
- **`uninstall.sh`: `remove_video_shotcraft` + `remove_ai_film_skills`** so both new packs round-trip cleanly.

### Added
- **`/humanizer` skill added to the copywriting module.** Third-party AI-tell scrubber from `blader/humanizer`, installed at pinned commit `523374d` (same rug-pull posture as the taste-skill and remotion packs). Codifies Wikipedia WikiProject AI Cleanup's "Signs of AI writing" into 33 checkable patterns: inflated significance, promotional language, superficial `-ing` analyses, vague attribution, AI vocabulary, copula avoidance, negative parallelism and tailing negations, rule-of-three padding, false ranges, aphorism formulas, manufactured punchlines, persuasive authority tropes, signposting, filler, hedging, sycophancy, curly quotes, emoji, title-case headings, and a hard ban on em/en dashes in the final rewrite. Three invocation modes (pasted text / file-in-place / embedded). Pairs with `/copywriting` as a strictly ordered second pass: draft with `/copywriting`, audit with `/humanizer`; running both on one draft at once produces mush. Installed by a new `install_humanizer_skill()` in `copywriting/install.sh` rather than the shared `install_skill_pack_pinned` helper, because `blader/humanizer` keeps `SKILL.md` at the repo root instead of under `skills/` and the generic discovery path would copy `.git` into `~/.claude/skills/humanizer/`. The dedicated function clones, checks out the pin, drops `.git` + `.github`, and copies the payload. Idempotent (skips when `SKILL.md` is already present) and soft-fails without git or network so the copywriting install still completes. Module self-test grows two assertions (SKILL.md present, no `.git` left behind). Root `install.sh` + `update.sh` banners, `uninstall.sh` (`remove_humanizer_skill`, before the watch removers), README (headline bullets, "What gets installed" table, "How I use" copywriting section, uninstall list), and CHEAT-SHEET (new "Humanizer" section + installed-paths row) all updated.
- **Claude-Watch module** (new fourth module alongside `design/` + `media/` + `copywriting/`). Installs the `/claude-watch` skill — drop any video URL (single video, full YouTube channel via `youtube.com/@handle/videos`, or playlist) and get back timestamped, frame-aware study notes. Under the hood: yt-dlp pulls the video, ffmpeg detects scene changes + extracts frames, captions (free, via yt-dlp) or local whisper.cpp (key-free, reusing the media module's `~/.whisper/ggml-base.en.bin` model) provides the transcript, and Claude reads every frame as an image to write a section-per-scene `notes.md` at `~/claude-watch/library/<slug>/`. Channel mode loops the per-video pipeline (default 10 videos, override with `--limit N`) and writes a top-level `index.md` rolling up the channel with a Cross-channel synthesis section (recurring hooks, thumbnail formulas, script structures, top 3 cloneable moves). Forked from `devinilabs/claude-watch` at `fidgetcoding/claude-watch` with two upstream-worthy patches: (1) local whisper.cpp shell-out backend so the skill runs key-free + offline, (2) channel/playlist detection via `yt-dlp --flat-playlist --dump-single-json`, plus a setup.py fallback that recognizes `~/.whisper/ggml-base.en.bin` so the two installers share one ~141MB model file. Ships SKILL.md + 11 Python scripts + a SessionStart hook + slash-command entry point (15 files total) vendored at `claude-watch-skill/` and installed via `claude-watch/install.sh` (downloads from `fidgetcoding/creativity-maxxing/main` with a local fallback). Root `install.sh` + `update.sh` now run `claude-watch/install.sh` after `copywriting/`. `uninstall.sh` removes `~/.claude/skills/claude-watch/` and the claude-watch user state (`~/.config/claude-watch/`, `~/claude-watch/library/`) before the ffmpeg prompt — the shared whisper model is only touched if the user accepts the `whisper-cpp` brew-uninstall path. Banner + "What gets installed" table + "How I use" subsection + cheat-sheet (new "Video study + channel sweep" section + installed-paths additions) all updated. Test harness: new `tests/test_claude_watch_install.sh` (58 assertions covering static contract + behavioral install w/ forced-local fallback + idempotency + prereq-fail + shared-model-path recognition); `tests/test_root_install.sh`, `tests/test_update.sh`, and `tests/test_uninstall.sh` extended with claude-watch shims + state-cleanup scoping assertions. Full suite 7/7 green (343 assertions).
- **Copywriting module** (new third module alongside `design/` + `media/`). Installs the `/copywriting` skill — a master-trained anti-AI-slop filter for headlines, hero copy, body copy, CTAs, manifestos, proposal docs, sales letters, landing pages, ad copy, brand voice, naming, and "rewrite this paragraph" requests. ## [1.0.0] - 2026-04-13

### Added — Initial extraction from cli-maxxing

`creativity-maxxing` was carved out of the original `cli-maxxing` step-4 + step-5 modules to keep the design / video / audio / transcription stack on a separate cadence from the core terminal install. Per `project_cli_maxxing_split` and `project_cli_maxxing_split_exec`.

- **Design module** (`design/install.sh`) — Figma MCP, Excalidraw MCP, Gamma MCP, Magic MCP, Canva MCP, Code Connect setup.
- **Media module** (`media/install.sh`) — Higgsfield Seedance video skills (15 templates), yt-dlp MCP, whisper-mcp transcription stack.
- `CHEAT-SHEET.md` — every slash command, skill, and MCP call exposed by the install in one reference page.
- Cross-platform install/uninstall/update scripts.
- Test suite — 5 files, all green at v1.0.0.
